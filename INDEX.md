## 🎯 Como Usar Este Repositório

### Para Usuários

1. **Ler:** `README.md` para entender o projeto
2. **Copiar:** `FRAMEWORK.md` para sua IA (ChatGPT/Claude)
3. **Aprender:** `docs/GETTING_STARTED.md` para tutorial
4. **Ver exemplos:** `examples/01_financial_analysis.md`

### Para Contribuidores

1. **Ler:** `CONTRIBUTING.md` para diretrizes
2. **Fork:** repositório no GitHub
3. **Criar:** novo caso de uso em `examples/`
4. **Abrir:** Pull Request

### Para o Autor (Você)

1. **Publicar:** seguir `docs/PUBLISHING_GUIDE.md`
2. **Manter:** responder issues, revisar PRs
3. **Evoluir:** lançar v2.1, v2.2 com melhorias
